Panoramic Vision:
Computational Streetscape Analysis

"Can we understand urban environments and street characteristics from Google Street View panorama images using Machine Learning and Stable Diffusion techniques?"

By Pruethicheth Lert-udompruksa, Siddharth Nambiar, Sharon Megan Wong and Soham Bhanushali  ·  Published May 27, 2024  ·  Updated June 13, 2024

Project Overview
This computational design project aims to develop a pipeline utilizing Grasshopper and Python to visualize clusters of panoramic streetscape images. The project leverages t-Distributed Stochastic Neighbor Embedding (t-SNE) for dimensionality reduction, facilitating the identification and analysis of patterns within the streetscape imagery. By clustering these images, we can gain insights into the visual characteristics and urban patterns of different neighborhoods.

STREET ANALYSIS is a tool that helps explore and understand streetscapes better. By using Google Street View images and machine learning, it allows users to select areas of interest and access detailed street information — from defining study areas to analyzing street characteristics. STREET ANALYSIS offers an experimental way to explore street patterns in urban environments.

Methodology

1 Defined Area and Data Gathering

The first step in the process is to define the area for analysis and gather the necessary data. Users can select any area for street analysis using Python and Grasshopper.

  • Area Selection
    • Python Script: A script allows users to select a boundary area based on coordinates, identifying the center points of streets from OpenStreetMap (OSM).
    • API Request: Using these coordinates, the script requests Google Street View data via API. In this example, a dataset provided in class is used.
  • Required Inputs
    • Google Street Panorama Images: Images with filenames for reference.
    • Shapefile of Streets: A shapefile representing the streets in the study area.
    • CSV File: A CSV file containing x and y coordinates and corresponding image codes.
  • Integration with Grasshopper
    • Inputs are connected and mapped to visualize the street images on a map.
    • Users can crop specific boundary areas for focused study, with image paths sent to the next process for depth analysis.
2 Depth Image Processing

An exposed API connection using Stable Diffusion through the A1111 framework enables the transformation of panoramic street images into depth images.

  • Conversion Process
    • The ControlNet (Midas) tool analyzes the color image and converts it into a depth image.
    • Lighter shades (closer to white) indicate objects nearer to the camera; darker shades (closer to black) represent objects further away.
    • This objectively indicates elements in the panorama that are closer or further from the center of the street.
  • Applications
    • Depth images help understand the spatial arrangement and distances within 2D images, providing a pseudo-3D perspective crucial for various analyses.
3 Image Clustering

The depth images were clustered using t-SNE for dimensionality reduction and K-Means clustering, with the optimal number of clusters determined by silhouette scoring. The script allows for either user-defined clustering or automated determination of cluster count based on dataset analysis.

The data collection involved gathering and pre-processing a substantial dataset of panoramic urban streetscape images from each neighborhood (barrio) of Barcelona.

  • Analysis Using Python
    • Python scripts read depth images from a directory and perform clustering analysis.
  • Clustering with t-SNE
    • t-Distributed Stochastic Neighbor Embedding (t-SNE) visualizes and clusters depth images accurately.
    • Identifies distinct groups based on depth information.
  • User-defined Clustering
    • Users set the number of expected clusters; the Python script automatically calculates and separates images into specified groups.
    • Clustered images are saved into respective directories.
4 3D Analysis and Visualizing

By interpreting the bar graph, users can understand the distribution of distances in the depth image. For instance, if most bars are tall in the lower range (0–30 m), many objects in the scene are close to the camera. Conversely, taller bars in the higher range (70–100 m) indicate most objects are far from the camera.

Interpreting the x and y axes of a depth image bar graph in terms of street quality provides valuable insights into the urban environment:

X-Axis — Depth Value Bins

  • Pedestrian Pathways — proximity of sidewalks and pedestrian zones
  • Street Furniture — distance to benches, bins, and similar objects
  • Building Fronts — proximity of building facades to the street
  • Vegetation — distance to trees, bushes, and greenery

Y-Axis — Frequency / Count

  • Street Clutter — high counts may indicate parked cars or dense furniture
  • Open Spaces — lower counts suggest pedestrian-friendly open areas
  • Uniformity — distribution pattern reflects consistency of building setbacks and street widths
5 Conclusion

Example Interpretation: Street Quality

  1. Even Distribution of Depth Values
    An even distribution across bins suggests a well-planned street with consistent building setbacks and well-placed street furniture — contributing to a balanced urban environment. This typically indicates high street quality, good urban planning, and strong accessibility.
  2. High Frequency in Short Depth Ranges
    A high frequency of pixels in short depth ranges (closer objects) could indicate narrow streets, closely packed buildings, or excessive street furniture. This might reflect lower quality in terms of open space and pedestrian comfort — but could also represent a vibrant, densely populated urban area.
  3. High Frequency in Long Depth Ranges
    A high frequency in longer depth ranges suggests more open space or wider streets. This can be positive, indicating spaciousness and better airflow — but if too sparse, might lack street activity and vibrancy.

This project demonstrates the integration of geospatial data collection, advanced image processing, and machine learning techniques to analyze urban street environments. The resulting visualizations and data analyses provide valuable insights into the city's street characteristics and distribution, supporting urban planning and development efforts.
